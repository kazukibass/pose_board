# Pose Board 要件定義書

更新: 2026-08-25
対象: v0.1

## 1. 目的

3D制作経験がないユーザーでも、最低限の3D人形を直接動かし、連続したポーズをコマとして保存・再生することで、短時間で動きの絵コンテを作れるWebアプリを提供する。

## 2. 基本原則

- 高機能より操作速度を優先する。
- 3Dはポーズ指定に必要な部分だけに限定する。
- 背景・文字・吹き出しは2Dレイヤーとして扱う。
- コマ数は固定しない。
- 動画を書き出さなくても編集画面で即座に動きを確認できる。
- AI生成は本体の責任範囲外とする。
- 将来拡張を妨げないが、将来機能のためにv0.1を複雑化しない。

## 3. 想定利用者

- キャラクターGIF / Spriteの動きを設計したい人
- ゲーム・アニメ・動画の簡易コンテを作りたい人
- 作画前にポーズを確認したい人
- AI画像生成へ渡す構図資料を作りたい人
- 絵を描けなくても動きや会話を視覚化したい人

## 4. 必須要件

### 4.1 3D Stage
- 簡易Rigを表示できる。
- モデル全体の位置・XYZ回転を変更できる。
- 各主要関節をXYZ回転できる。
- 固定カメラからSceneを確認する。
- 複数Actorを将来追加可能な構造とする。

### 4.2 Rig Preset
初期候補:
- 成人男性
- 成人女性
- 男児
- 女児
- 犬
- 猫
- 2頭身SD
- 4頭身デフォルメ

人型は可能な限り共通骨格を使い、プロポーション差として定義する。犬猫は四足Rig系として扱う。

### 4.3 Timeline / Frame
- 任意数のコマを保持できる。
- コマ追加
- 前コマ複製
- コマ削除
- ドラッグ等による順序変更
- 任意コマを選択して再編集

### 4.4 Preview
- 再生 / 停止
- ループ再生
- FPS変更
- Timeline順を即時反映
- 動画生成を行わずSceneを順番に切り替えて表示する

### 4.5 Background
- 透過
- 単色
- カラーピッカー
- 白 / 黒 / グレー / グリーンバック等のプリセット
- PNG / JPEG / WebP等の2D画像取込
- 画像位置・拡大縮小

背景はカメラ後方の2D Backdropとして扱い、3D背景機能は持たない。

### 4.6 Overlay
- テキストボックス
- 吹き出し
- 移動
- サイズ変更
- 内容編集

### 4.7 Save / Load
- 編集可能なプロジェクトデータを保存できる。
- 保存データから編集状態を復元できる。
- フレームは画像ではなくScene Stateを中心に保持する。

### 4.8 Export
v0.1で最低限:
- 現在コマのPNG
- 全コマの画像出力

候補:
- Sprite Sheet
- GIF

## 5. 非機能要件

- ブラウザ上で軽快に動作すること。
- サーバー依存を可能な限り減らすこと。
- PCを第一対象としつつ、将来的なタッチ操作を阻害しないUIにする。
- 主要操作は数クリック/ドラッグで完結すること。
- 外部3Dモデル素材を使わなくても動作すること。

## 6. v0.1対象外

- AI生成
- 3D背景
- 本格モデリング
- テクスチャ制作
- 物理演算
- 自動中割り
- カメラの連続移動
- 漫画ページレイアウト
- 任意3DモデルのRig編集

## 7. 将来互換性として確保するもの

- Frame IDは単純な配列番号に依存しない。
- Actorは配列化可能なデータ構造にする。
- Actor typeを持たせ、primitive-rig以外を将来追加可能にする。
- Frameにdurationを追加可能にする。
- Camera IDを保持できるようにする。
- SceneをTimeline以外のPage Layoutから参照できる構造を想定する。
